# sorry - 잘못한 점 찾기

예능 화면 한 장면을 클릭하면, 클릭한 위치에 맞춰 A4 사과문이 자동으로 만들어지고 바로 인쇄(PDF 저장) 창이 뜨는 웹 작업.

손가락 끝, 빈 의자, 화이트보드의 점 세 개처럼 사소한 화면 구석도 "논란"이 되고, 사과문은 매번 같은 형식으로 고개를 숙인다. 무엇이든 사과의 대상이 될 수 있는 방송 사과문의 형식을 가지고 논다.

## 동작

- 장면 5개(편의점 야식 대결, 시골 부엌 요리 소동, 오답 폭발 퀴즈쇼, 강변 캠핑 생존기, 직장인 역할극 회의)가 순서대로 나온다.
- 장면마다 숨은 지점(hotspot)이 있다. 클릭한 좌표에서 가장 가까운 지점을 골라 논란 제목, 책임 주체, 경위, 재발 방지 약속을 채운다.
- 사과문에는 생성 시각과 클릭 좌표가 들어가고, `window.print()`로 A4 한 장이 출력된다.
- 인쇄가 끝나면 다음 장면으로 넘어간다.

## 실행

빌드 없음. `index.html`을 브라우저로 열거나 정적 서버로 띄운다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 구성

- `index.html` - 장면 버튼과 인쇄용 사과문 레이아웃
- `script.js` - 장면·지점 데이터, 클릭 좌표 계산, 사과문 문장 생성
- `style.css` - 화면/인쇄(A4) 스타일
- `assets/` - 장면 이미지 (작가가 직접 생성한 이미지, 실제 방송 캡처 아님)
